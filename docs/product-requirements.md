# 제품 요구사항

## 1. 제품 정의

마이데이터 기반 소비 분석으로 사용자의 카드 선택을 돕고, 제휴사가 자사 홈페이지에 필요한 기능만 삽입할 수 있도록 제공하는 B2B2C 카드 추천 서비스다.

## 2. 주요 사용자

### 최종 사용자

- 자신의 소비 패턴을 이해하고 싶은 사용자
- 여러 카드 중 실질적인 혜택이 큰 카드를 찾는 사용자
- 이사, 여행, 취업 등 변화한 상황을 카드 선택에 반영하고 싶은 사용자

### 제휴사 운영자

- 자사 서비스에 카드 추천 기능을 빠르게 도입하려는 기업
- 제휴사별 테마와 노출 정책을 관리하려는 담당자

### 서비스 운영자

- 카드 상품과 혜택 정보를 관리하는 담당자
- 추천 품질, 연동 상태, 장애를 확인하는 담당자

## 3. 핵심 사용자 흐름

1. 사용자가 제휴사 서비스에서 로그인한다.
2. 사용자는 마이데이터 활용 범위에 동의한다.
3. 서비스가 사용자의 합성 거래 내역을 카테고리별로 분석한다.
4. 추천 엔진이 소비 패턴과 카드 혜택을 비교한다.
5. 사용자는 예상 혜택과 추천 이유가 포함된 카드 목록을 확인한다.
6. 사용자는 AI 상담사에게 자신의 상황을 추가로 설명한다.
7. AI 상담사는 추천 결과와 카드 문서를 근거로 답변하고 출처를 표시한다.

## 4. MVP 범위

### 인증 및 권한

- 이메일 회원가입과 로그인
- Access Token과 Refresh Token 발급
- Spring Security 기반 API 권한 제어
- 사용자·제휴사 운영자·서비스 운영자 역할 분리
- 제휴사 식별자 기반 데이터 접근 제한

### 합성 마이데이터

- 사용자, 계좌, 보유 카드, 거래 내역 생성
- 거래 일시, 금액, 업종, 결제수단, 가맹점 정보 제공
- 월별·카테고리별 소비 집계
- 테스트 시 동일한 데이터를 재생성할 수 있는 Seed 지원

### 카드 추천

- 카드별 혜택 조건과 한도 모델링
- 사용자 소비 데이터 기반 예상 혜택 계산
- 상위 추천 카드와 점수 제공
- 추천에 영향을 준 소비 항목과 혜택 근거 제공
- 동일 입력에 대해 동일 결과를 내는 결정적 추천 로직

### AI 상담

- 텍스트 상담
- 사용자 상황을 구조화된 조건으로 변환
- 추천 엔진 결과를 바탕으로 답변
- 카드 혜택·약관 검색과 출처 표시
- 근거가 없거나 확실하지 않으면 답변 보류
- 음성 입력과 출력은 텍스트 상담 안정화 후 추가

### 삽입형 모듈

- MyData Summary, Recommendation, AI Advisor를 개별 컴포넌트로 제공
- 제휴사별 테마 토큰 지원
- 초기화 설정으로 제휴사와 사용자 세션 전달
- 허용된 Origin에서만 모듈 사용
- 독립 페이지와 삽입 화면 양쪽에서 동일 API 사용

## 5. 비기능 요구사항

### 보안과 개인정보

- 실제 개인정보와 금융정보를 저장하지 않는다.
- 비밀번호는 단방향 해시로 저장한다.
- 비밀값은 코드와 Git에 포함하지 않는다.
- 민감정보를 애플리케이션 로그에 기록하지 않는다.
- 최소 권한 원칙과 입력 검증을 적용한다.

### 성능

- 성능 목표는 기준 API 구현 후 측정하여 확정한다.
- 최대 100만 건의 합성 거래 데이터로 조회 성능을 검증한다.
- 평균만이 아니라 p95 응답 시간을 기록한다.
- 인덱스와 캐시 적용 전후 결과를 비교한다.

### 안정성

- Redis 장애 시 핵심 조회가 MySQL로 동작해야 한다.
- 외부 AI 서비스 장애 시 일반 추천 기능은 유지되어야 한다.
- 중복 요청과 동시 요청에 대한 테스트를 작성한다.
- AWS 배포 후 로그, 지표, 알람과 복구 절차를 마련한다.

### 접근성 및 UX

- 추천 점수만 보여주지 않고 이해 가능한 이유를 제공한다.
- 키보드만으로 주요 기능을 사용할 수 있어야 한다.
- 색상 외의 정보 표현 수단을 함께 사용한다.
- 로딩·빈 결과·오류·재시도 상태를 명확히 제공한다.

## 6. MVP에서 제외

- 실제 금융기관 마이데이터 연동
- 실제 카드 발급 및 결제
- 결제·구독·정산 시스템
- 별도의 NestJS 백엔드
- 필요성이 검증되지 않은 Elasticsearch와 메시지 큐
- 운영기관의 승인 없이 수행하는 웹 크롤링

## 7. 성공 기준

- 신규 사용자가 소비 분석부터 카드 추천 이유 확인까지 완료할 수 있다.
- 제휴사 예제 페이지에 세 가지 모듈을 각각 삽입할 수 있다.
- 추천 결과가 테스트 데이터의 기대 결과와 일치한다.
- AI 답변이 추천 엔진 결과를 바꾸지 않으며 근거를 표시한다.
- MySQL과 Redis 적용 전후 성능 자료가 존재한다.
- AWS에서 HTTPS로 접근 가능하고 자동 배포와 롤백 절차가 검증된다.
