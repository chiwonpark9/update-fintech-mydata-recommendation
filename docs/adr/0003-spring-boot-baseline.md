# ADR-0003: Java 17과 Spring Boot 4.1.1을 백엔드 기준으로 사용한다

- 상태: 승인
- 날짜: 2026-08-30

## 배경

첫 백엔드 골격을 만들기 위해 Java 버전, Spring Boot 버전, 빌드 도구와 초기 의존성을 결정해야 한다. 새 프로젝트인 만큼 공식 지원 범위 안에 있는 안정 버전을 사용하고, 기능을 구현하지 않은 라이브러리를 미리 추가하지 않는 기준이 필요하다.

## 결정

- Java 17을 언어와 실행 환경의 최소 버전으로 사용한다.
- Spring Boot 4.1.1을 사용한다.
- Gradle은 전역 설치 대신 프로젝트에 포함된 Gradle 9.7.1 Wrapper로 실행한다.
- 초기 의존성은 Spring Web MVC, Validation, Actuator로 제한한다.
- 데이터베이스와 보안 의존성은 해당 기능을 구현할 때 추가한다.

## 이유

- Java 17은 현재 로컬 환경과 호환되며 Spring Boot 4.1.1의 최소 요구사항을 만족한다.
- Spring Boot 4.1.1은 프로젝트 생성 시점에 Spring Initializr가 제공하는 기본 안정 버전이다.
- Gradle Wrapper는 개발자와 CI가 동일한 Gradle 버전을 사용하게 한다.
- 필요한 의존성만 추가하면 자동 설정의 범위와 문제 원인을 이해하기 쉽다.

## Health API 구분

- `/api/v1/health`는 프론트엔드와 백엔드의 API 통신 계약을 확인한다.
- `/actuator/health`는 로드 밸런서와 모니터링 시스템이 운영 상태를 확인한다.

두 엔드포인트의 목적을 분리하여 애플리케이션 응답 형식과 운영 상태 정보를 독립적으로 변경할 수 있게 한다.

## 결과

- 백엔드는 Java 17 이상에서 실행해야 한다.
- 빌드와 테스트 명령은 `./gradlew`를 기준으로 문서화한다.
- 새 의존성을 추가할 때는 해당 기능과 검증 방법을 함께 기록한다.
