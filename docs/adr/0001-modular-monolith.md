# ADR-0001: 모듈형 모놀리스로 시작한다

- 상태: 승인
- 날짜: 2026-08-30

## 배경

서비스는 인증, 마이데이터, 카드, 추천, AI 상담, 제휴사 연동처럼 여러 도메인을 포함한다. 도메인 경계는 필요하지만 현재는 한 명이 학습과 구현을 병행하는 초기 단계다.

## 결정

백엔드를 하나의 Spring Boot 배포 단위로 구성하되, 도메인별 패키지와 의존성 경계를 명확히 분리하는 모듈형 모놀리스로 시작한다.

## 이유

- 로컬 실행과 테스트, 배포 구성이 단순하다.
- 분산 트랜잭션과 네트워크 장애를 조기에 떠안지 않는다.
- 하나의 기능을 끝까지 구현하는 데 집중할 수 있다.
- 도메인 경계를 유지하면 필요할 때 일부 모듈을 분리할 수 있다.

## 결과

- 초기 개발과 AWS 배포는 하나의 백엔드 애플리케이션을 기준으로 한다.
- 다른 도메인의 내부 구현에 직접 의존하지 않고 공개된 애플리케이션 인터페이스를 사용한다.
- 추천 계산과 AI 상담은 같은 배포 단위에 있더라도 역할을 분리한다.

## 재검토 조건

다음 중 하나가 실제 측정으로 확인되면 서비스 분리를 검토한다.

- 특정 모듈만 독립적인 확장이 반복적으로 필요하다.
- 배포 주기와 장애 격리 요구가 명확히 다르다.
- 서로 다른 런타임이나 보안 경계가 반드시 필요하다.
